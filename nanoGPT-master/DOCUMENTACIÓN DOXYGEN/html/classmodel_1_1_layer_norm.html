Detailed Description

@brief Capa encargada de normalizar las representaciones internas del modelo.

@author Andrej Karpathy
**Documentación en español:** *Josué Aybar Paulino*

@details

La clase **LayerNorm** es una capa que normaliza los valores internos del modelo para mantenerlos en una escala estable,
facilitando el entrenamiento de los bloques Transformer. La función `__init__` crea los parámetros entrenables `weight`
y `bias` según la dimensión del embedding (ndim), que en este modelo corresponde a 768 dimensiones. También permite
definir si se utilizará el término de sesgo. La función `super()` inicializa la clase base de PyTorch para que esta
capa pueda ser gestionada como un componente entrenable. Finalmente, `forward()` recibe los datos numéricos de entrada
y aplica la normalización mediante layer_norm antes de continuar el procesamiento dentro del Transformer.
