Detailed Description

@brief Bloque Transformer de GPT.

@author Andrej Karpathy
**Documentación en español:** *Josué Aybar Paulino*

@details

Integra los componentes principales de un bloque Transformer:
- `LayerNorm`: normalización para estabilizar el entrenamiento.
- `CausalSelfAttention`: atención causal sobre el contexto previo.
- `MLP`: transformación no lineal de las representaciones.

## Flujo
`__init__()` inicializa los componentes.
`forward()` aplica normalización, atención causal, MLP y conexiones residuales.
